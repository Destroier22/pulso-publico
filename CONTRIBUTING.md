# Como contribuir

1. Abra uma issue descrevendo o problema, a fonte e o impacto.
2. Crie uma branch curta e focada.
3. Preserve a rastreabilidade: todo novo indicador precisa de fonte, definição, período e limitação.
4. Execute `npm test` e `npm run build`.
5. Em mudanças de dados, explique se o diff veio de retificação oficial ou alteração metodológica.

Não inclua chaves, tokens, dados pessoais ou artefatos gerados localmente.
